# Supplementary data — v3.0.0

This directory contains the numerical datasets used for the manuscript reproducibility workflow.

- S1: 231-composition descriptors, reference scores and robustness statistics.
- S2a/S2b: 10,000-draw single-junction and tandem scoring-model sensitivity samples.
- S3a/S3b: 5,000-draw coherent descriptor-calibration stress inputs and summary.
- S4: weight-free four-objective Pareto classification.
- S5: Latin-hypercube sample-size convergence diagnostic.
- S6: Hooper et al. (2026) synthesis-resolved bromide optical challenge.
- S7a: composition-level combined calibration/nonlinear model-form stress summary.
- S7b: complete 10,000-draw, 19-dimensional model-form stress parameter set.
- model_form_summary.txt: compact Code 3 cross-check output.

S1–S3 are generated by `../Supplementary_Code_1.py`; S4–S6 by `../Supplementary_Code_2_revision_checks.py`; and S7a–S7b by `../Supplementary_Code_3_Model_Form_Stress.py`. Fixed random seeds are embedded in the scripts and documented in the manuscript/Supporting Information.
