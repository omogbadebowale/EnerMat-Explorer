# Manuscript figures — v3.0.0

This directory contains committed legacy manuscript figures from v2.0.0 and is the output directory for the v3.0.0 figure-generation routines.

- `Supplementary_Code_1.py` regenerates the original workflow, trade-off, landscape and Supplementary Figures S1–S4.
- `Supplementary_Code_2_revision_checks.py` generates the LHS convergence, weight-free Pareto, independent synthesis-resolved optical-challenge and TOC graphics.
- `Supplementary_Code_3_Model_Form_Stress.py` generates the combined calibration/nonlinear model-form stress figure.

The v3 scripts export high-resolution publication PNGs and, for the added revision figures, SVG files suitable for journal production.
